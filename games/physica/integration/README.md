# PHYSICA Arcade integration — removed

The user requested removal from Forge Arcade on 15 November 2026, superseding the earlier hidden integration. The footer atom shortcut, its CSS and the active root physica-register.js were removed. PHYSICA is no longer registered or linked by the launcher.

ELEMENTAL remains hidden behind its chemistry flask and the visitor counter is preserved. The Arcade has 40 registered entries and 39 visible cards. Standalone PHYSICA source, original artwork, tests and direct game files are retained; this is a launcher removal, not deletion of the standalone project. The registration copy in this directory is historical and is not loaded.

The replacement test tests/physica-removal-browser.cjs verifies no physics symbol, registration or game listing; unchanged visible count; chemistry flask launch into both ELEMENTAL laboratories; visitor counter; and desktop/mobile layouts.
