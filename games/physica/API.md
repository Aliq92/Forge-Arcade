## Common lab interface

Every lab module exports `LAB_ID` ('gravity'|'motion'|'waves'|'electricity'), `EXPERIMENTS` (4 descriptors), `PARAMETERS` (mode-keyed arrays), `createModel(mode,params={})`, `normalizeConfig(mode,params)->{ok,config,errors}`. `createModel` throws understandable Error for invalid inputs, never leaves partial unusable state. ES module .js files. GUIDED IDs exact G1..G4,M1..M4,W1..W4,E1..E4.

Descriptor `{id,lab,mode,title,objective,prediction,explanation,equations:[strings],assumptions:[strings],defaults:plainJSON,graph?:{x:'time',y:'speed',reference?:...}}`. All16 must have actual working setups. Scientific explanatory strings original concise, no copied long passages. PARAMETERS `{mode:[{key,label,unit,min,max,step,default,type?:'number'|'boolean'|'select',options?:[{value,label}]}]}`. Schema includes every numeric parameter; units SI unless angle controls labelled degrees and explicitly converted. Objects configuration edited separately via root inspector, never arbitrary code. Unknown unsafe fields/nonfinite/type/range errors rejected; avoid inherited object map keys. Each model `.config` is normalized editable initial setup, not live data.

Model fields `.lab,.mode,.config,.time` physicalSI seconds, `.dt` fixed physical step, `.clockRate` physical seconds per real second at1×, `.state` plain renderer-observable data, `.warnings` array of strings, `.valid` boolean, `.complete`boolean (natural terminal e.g landed; static/oscillator/orbits maynever complete). Methods `.step(dt=this.dt)` one physicalstep (rootalways passes .dt), `.measure()->{key:number|null,...}`, `.snapshot()` deep plainJSON view state. `.measurementMeta` mapkey→`{label,unit}`; include `time` s. State finite under allowedbounds; null represents unavailable measurement (not0/fabricated period). Measurement/graph values from actual state, analytical comparisons explicitly separate `.theory` dictionary. No random physics. Rendering never changes model or force laws. Reset/rebuild=new model from same normalized config. Document numerical scheme/timestep/limitations and emit meaningful warnings for difficult cases; no silently misleading outputs. Time and measuretime same units. Terminal .step may no-op; circuit step increments time ifvalid.
