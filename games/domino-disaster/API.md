# Domino Disaster shared implementation contract

The supplied BRIEF.md is binding; this contract fixes module boundaries and data interfaces. Vanilla ES modules, no runtime libraries. Physics/levels/editor are pure and testable without DOM. Root owns game.js, editor.js, input.js, audio.js, storage.js, main.js, index/style and integration/docs. Physics owner owns physics.js/gadgets.js/objects.js and their tests; content owner owns levels.js/level tests; visual owner owns renderer.js/renderer tests/local vector art. No shared Arcade edits, staging, branch changes or publication by agents.

## World and board

True2D world units are pixels: origin top-left, x right, y down; angle radians clockwise. Default1000×620, gravity800px/s², floor top550. A typical domino14×56 mass1; marble radius10 mass1.5; ramp100×10 static; spring34×18 static; gear radius22 static/collidable with explicit mechanical coupling; seesaw120×10 rotates only around fixed center; switch28×10 and finish30×44 are contact sensors. Decorative depth never changes collision. Standard resting domino center atfloorY−28; marble atfloorY−10.

Board `{version:1,id:number|'sandbox',title,width,height,gravity:800,seed:1,platforms:[{id,x,y,w,h,angle:0}],objects:[spec],links:[{from,to}],start:null|{id,impulse?:{x,y},point?:{x,y}},inventory:{domino:n,...},forbidden:[{x,y,w,h}],maxObjects:64,timeLimit:25,objectives:{required:[IDs]},starBudget:{two:8,three:6},tutorial,hint,solution:[editorActions]}`. x/y of platforms/specs are centers; forbidden x/y top-left. Dimensions boundedwidth400–2400,height300–1400,gravity0–1400,timeLimit5–60. Maximum120 gadgets+16platforms, with safeunique IDs acrossboth, links<=120. Empty Sandbox valid withstart:null, noobjectives. Puzzles require a start and at leastone finish. SafeIDs alnum/hyphen/underscore; reject inherited prototype names, nonfinite values, invalid types/settings/references, excessive collections. Strings are rendered with textContent.

Spec `{id,type,x,y,angle:0,locked:false,name?,color?,style?,settings?:{strength?:300,accept?:'any'|'marble'|'domino'}}`. Types exactly domino,marble,ramp,spring,gear,seesaw,switch,finish. **locked means editor-fixed, not physically static**: a locked starting domino stillfalls dynamically. Physical type setsstatic/dynamic/pivot. Config angle forspring islaunchdirection, gearinitialphase, seesaw initialtilt (boundmax±0.55); rampsangle within±1.35; normaldomino within±π; springstrength150–650px/s impulse velocity increment; finish/switch acceptmovingbodytype defaultany. Colors limited palette names/hex via strictvalidator. Palette turquoise/gold/coral/lavender/mint/orange/navy. Root editor uses defaultdimensions fromCATALOG. No arbitrary user functions or scripts.
