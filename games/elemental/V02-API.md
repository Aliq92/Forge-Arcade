# v0.2 interfaces and ownership

All modules are browser/Node ES modules with no DOM in chemistry/storage/catalogue modules. No changes to old atomic data or progress key. IDs are stable scientific identities, separate from reagent forms and display labels.

## Catalogue and discovery task

Own src/discovery/catalog.mjs, src/discovery/store.mjs, src/reaction/store.mjs, tests/discovery.test.mjs and tests/reaction-store.test.mjs. No UI files.

`createCatalog(elements,isotopes,refs)` returns `{all, get(id), reagents, reagent(id)}`. Entries: `{id,name,formula,category,elements:{H:2,O:1},charge,representation,referenceId?,reactionForms:[],notes,molarMass}`. Immutable definitions; missing lookup returns null. Molecule IDs reuse refs (H2,O2,N2,H2O,CO2,NH3,CH4,C2H4,C2H2). Element IDs element:H; neutral verified atoms atom:H:1; isotopes isotope:H:1; supported ions ion:Na:1, ion:Cl:-1 etc. Ionic species additionally ion:OH:-1, ion:HCO3:-1, ion:CO3:-2. New neutral compound IDs NaCl,sucrose,ethanol,hexane,HCl,NaOH,NaHCO3,CaCl2,Na2CO3,CaCO3. Formula parsing/composition and molar mass belong only here.

Reagent IDs and definitions: water→H2O(l), salt→NaCl(s), sugar→sucrose(s), ethanol→ethanol(l), hexane→hexane(l), acid→HCl(aq), base→NaOH(aq), bicarbonate→NaHCO3(aq), calcium→CaCl2(aq), carbonate→Na2CO3(aq), hydrogen→H2(g), oxygen→O2(g), nitrogen→N2(g), carbon-dioxide→CO2(g), ammonia→NH3(g), methane→CH4(g), ethene→C2H4(g), ethyne→C2H2(g). Forms `{id,speciesId,state,unit:'mL'|'mmol',defaultQuantity,maxQuantity,stock,starter:boolean,color,texture,concentration?,density?}`. Starter water/salt/sugar/ethanol/hexane/acid/base/bicarbonate/calcium/carbonate. Others unlock by eligible discovery. Water/liquid quantities mL; solids/gases/solution solutes mmol. Stocks are finite per trial. Water density approximation 1g/mL; ethanol .789g/mL; hexane .659g/mL, approximate educational at room temperature. Aqueous stocks concentration .1 mol/L; stock carrier water is included in ledger with volume q/.1 mL. Solids max100mmol, solutions max10mmol, gases max10mmol, liquids max200mL; summed solution volume max500mL. Neutral elemental H/O/N discoveries unlock appropriate H2/O2/N2 forms, not arbitrary salts; isotope-specific samples unsupported.

`DiscoveryStore(catalog,storage?)`: fields `.records` array `{id,sources:[],firstSeen}`, `.error`; methods `.record(id,source)->boolean` (true new, false duplicate), `.has(id)`, `.available()->entry[]` (with sources), `.importForm(id)->{ok,forms:[],reason}`, `.discoverElement(symbol)`, `.discoverAtom({z,a,q})`, `.discoverMolecule(referenceId)`, `.recordProducts(items)` (items speciesId/amount/state), `.migrateLegacy(progress)` safe idempotent mapping of validated completed sequential challenges. Only elemental.discovery.v1; no live state in records. Sources atomic-lab/reaction-lab. `save()` best effort and reports error; blocked getter tolerated. Validate stored IDs/sources/timestamps/schema; retain corrupt/future data until an explicit successful write rather than rewriting on construction. Legacy old record never overwritten by migration.

`ReactionStore(catalog,storage?)`: `.data={v:1,inventory:[],setups:[],journal:[],completed:[],achievements:[],tutorial:false}`, `.error`, `.save()`, `.addInventory(formId)` unlocks form only (no quantity creation), `.saveSetup(name,config)`, `.recordRun(experimentId,config,result)->boolean` journal dedup by deterministic normalized trial signature, `.exportSetup(config)->string`, `.parseSetup(text)->config`, `.importSetup(text)->config`, `.saveSession(config)`, `.session` initial config. Journal max100; setups max8. Catalogue ids/known forms, finite numbers, dates, reaction IDs, experiment IDs, schemas validated. Does not import engine; use contract config validation shared or local strict validation. Actual completion is recorded only for verified outcome, not on failed/unsupported trials. All arrays bounded; no prototype injection.

## Engine/content task

Own src/reaction/chemistry.mjs, src/reaction/experiments.mjs, tests/reaction-engine.test.mjs and REACTION-SCIENCE.md. Consume catalogue, never duplicate identity compositions/formulas. `normalizeConfig(config,catalog)->{ok,config,errors}` and `simulate(config,catalog)->result` (invalid yields valid:false/errors, no throw). Config `{reagents:[{formId,quantity}],temperature:25,vessel:'beaker'|'flask'|'sealed',activation:false,solventFraction:1}`; max6 distinct forms, duplicate forms merged only within stock limit; temperature -10,25,110 (non25 only pure-water phase); solventFraction .05..1, only salt/water recovery. Pure immutable input→output.

Result `{valid,supported,process,ruleId,effect,equation,explanation,observations:[],warnings:[],initial:[{speciesId,amount,state}],products:[{speciesId,amount,state}],remaining:[...],final:[...],extent,limiting:[],conservation:{atoms:true,charge:true,massError,atomResiduals,chargeResidual},measurements:{massG,volumeMl,pH:null|number,temperature:setting,pressure:null},...}` amounts always mmol; result products newly formed/changed, final conserved ledger including spectators, excess, solvent and gas, not just named products. Unsupported valid:true/supported:false and exact heading NO VERIFIED REACTION AVAILABLE; no outcome effect. No fabricated reaction for extra unexplained forms. Models and limits explicit.

`REACTIONS` exported array curated net rules with reactants/products coefficients and physical states. Models: NaCl finite dissolution at25°C capacity36g/100g water (PubChem CID5234); dilute sugar dissolution (enforce domain, preserve identity); water/ethanol miscibility and water/hexane immiscibility; H+ +OH−→H2O ideal strong neutralization with spectators; H+ +HCO3−→CO2+H2O ideal gas evolution; Ca2+ +CO3²−⇌CaCO3 reduced free-ion Ksp8.7e-9 at25°C (OpenStax AppendixJ) with residual ions and dilution handling; pure-water equilibrium phase endpoints at-10/25/110°C nominal1atm; solvent recovery re-equilibrates salt and retains removed water as gas ledger; optional 2H2+O2→2H2O only sealed+virtual activation, no real-world procedures. Curated pair matching avoids unsupported general-mixture predictions. pH only dilute strong-acid/base25°C supported system, includes Kw1e-14; unknown in carbonate/other liquids. No predicted real thermal temperature/pressure/yield. Crystal/phase/dissolution equation identity correct. Guided collection at least8 covering those outcomes, independent actual-state challenge predicates optional3. Export `EXPERIMENTS` with `{id,title,objective,prediction,equipment,config,explanation,expectedProcess}` and `CHALLENGES` optional actual-result checks. Engine tests independent analytical references incl dilute no-precip, limiting/excess, unsupported third form, repeat-run identity, malformed JSON/numbers, conservation sweep. Scientific sources below.
