## Display axis scaling

Scenes can opt into `aspect: "independent"` for plots whose horizontal and vertical coordinates have distinct quantities or scales. Profile helpers emit this flag. The renderer fits each axis independently and labels the coordinates; pan/zoom applies consistently to both axis transforms. Omit the flag for physical spatial geometry so equal world lengths retain equal screen scales. PlotCanvas always uses separately labelled independent data axes.
