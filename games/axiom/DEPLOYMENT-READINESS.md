# AXIOM hidden integration

User approval: 16 November 2026. Integrate as a hidden physics institute accessed through an atom symbol in the Forge Arcade footer, beside ELEMENTAL’s flask.

The active root `axiom-register.js` registers `hidden: true` and `featured: false`. `axiom-secret.css` gives the symbol a 44-pixel touch target, hover feedback and keyboard focus outline. Root `index.html` contains its accessible SVG link and registration. AXIOM stays absent from all cards, category/featured collections and counts. The visible count stays 39; PHYSICA is not restored, and chemistry remains hidden under its flask.

The old `integration/axiom-register.js` and card patch are an archived visible-card proposal, superseded by the user’s footer-symbol instruction. Do not apply them to the active site. Pixel artwork remains available but is not listed.

Runtime is native static HTML/CSS/ES modules under `games/axiom`; no remote runtime dependencies or build framework. Scientific suite: 159 checks. Prior final review approved all scientific/UI fixes; physical phones, non-Chrome browsers and screen readers remain untested. Tests/axiom-hidden-browser.cjs checks the actual hidden registration, all filters, visible count, keyboard/touch footer entry, physics stepping, notebook save, return link and unchanged chemistry at desktop/mobile sizes. Public verification results are recorded in QA.md after deployment.
