# NEON FORGE implementation contract

Vanilla ES modules, Canvas2D. Root owns UI, input, storage, audio and integration. Pure simulation owns all rules; renderer never mutates gameplay. No shared Arcade edits or publication.

## Coordinates and tuning

Arena world origin at robot center, x right/y down; radians atan2(y,x), clockwise. World radius280, target spawn radius270. Robot fixed center; danger radius30; strike reach132, half-arc25 degrees (50 total); active0.10s plus recovery0.22s =>0.32s start-to-start. An active strike freezes its angle and tracks each target once. Keyboard rotation3.5rad/s. Target speed bounded<=74. Perfect region radius86 ± speed*0.05 (100ms traversal window). Target radius is visual only; collision uses target center in exact arc/radius, swept movement as needed at1/120s. Bulwark2HP. Splinter children appear farther out (>=154) at angle±0.14 with readable distinct small silhouettes; cannot hit player or be hit by the spawning attack immediately.
