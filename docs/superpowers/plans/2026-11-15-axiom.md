# AXIOM implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent model/content tasks, scoped task reviews and a final whole-branch review. Work continuously through all milestones; no deployment.

**Goal:** A complete static physics institute with ten meaningful disciplines, substantive validated experiments, honest theoretical frontiers, equation exploration, a connected curriculum and a local research notebook.

**Spec:** games/axiom/BRIEF.md. Binding implementation contract: games/axiom/API.md.

**Architecture:** Separate pure physical models, reviewed educational content and generic Canvas/DOM app. Reuse independent copies of PHYSICA's validated SI modules, never its gamification or progress schema. General scene primitives carry actual physical coordinates; the renderer owns only display camera/styling. Analytical models expose actual parameter curves; conceptual models are prominently labelled and never predict unknown particles or dimensions. Native semantic equation rendering, no remote runtime dependency.

**Tech stack:** Vanilla ES modules, Canvas2D, CSS/DOM, localStorage, existing Node/Playwright tests. No backend or external runtime requests.

## Constraints and review focus

- Only games/axiom and this plan change. ELEMENTAL and archived PHYSICA are preserved; the latter is not re-registered.
- Development branch codex/axiom from published4bbd3bb. No merge/push/public deployment without explicit authorization.
- No scores, enemies, achievements or arcade challenges. Scientific Discoveries is a historical/evidence timeline.

- Substantial bounded models, not hundreds of decorative placeholders. Approximate/analytical/conceptual domains are explicit.
- Notebook preserves initial configurations, observations and actual graph samples, capped counts; comparisons require compatible axes/units. No accidental old-game save writes.
- Review singular/invalid parameters, field-source singularities, horizons, quantum normalization, analytic boundaries, thermodynamic energy/entropy, inaccessible controls, storage failure/corruption and tab/mode lifecycle.

## Inspection and decisions

PHYSICA's four pure SI model files are independent of its UI. All68 existing scientific/session tests pass before reuse. Four copies are retained under AXIOM's physics/reused directory; provenance and unchanged-source checks will document adaptations. ELEMENTAL v0.2 uses navy/cyan semantic DOM, explicit models and separate save namespaces; AXIOM follows that clarity. Root registration uses GAMES.push with Games/Simulations/Experiments categories and hidden filtering. Prepared AXIOM metadata uses Experiments with Science/Education metadata, no active root edits. GitHub Pages serves static files; build.mjs copies native documents. Test infrastructure is Node + installed Chrome/Playwright.

Ruling: finite representative models and grouped lessons cover the complete requested curriculum, with explicit limits instead of false full-scale simulators. Tensor/operator equations use selected solvable examples and guided derivations; conceptual frontiers make no new physical numerical predictions. The cost if this scope is insufficient is adding further validated models, not relabelling current approximations as complete theories.
