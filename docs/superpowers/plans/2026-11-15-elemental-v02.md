# ELEMENTAL v0.2 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for the independent scientific model and persistence tasks, with scoped task reviews and a final whole-branch review.

**Goal:** Preserve Atomic Lab and add a complete, independent Reaction Lab connected only by a shared scientific Discovery Library.

**Architecture:** Existing atomic modules remain in place. A centralized immutable identity catalogue derives elements, isotopes, ions and reference molecules from the existing source datasets, adding only new reaction identities. Separate atomic progress, shared discovery IDs and reaction session/journal saves prevent live-state coupling. A pure, curated, deterministic chemistry engine supplies both guided and free mixing; a separate UI and outcome renderer consume its results.

**Tech stack:** Vanilla ES modules, existing local Three.js for molecule inspection, Canvas2D reaction vessel, native accessible DOM. No external runtime requests.

**Spec:** User attachment copied to games/elemental/V02-BRIEF.md. API contract: games/elemental/V02-API.md.

## Global constraints

- Atomic Lab remains fully functional and recognizable; all 12 challenges and the old elemental.progress.v1 record must survive.
- Independent Atomic and Reaction interfaces and live states. Only identity discovery availability crosses modes.
- No unrelated game, root gallery, hidden shortcut, shared stylesheet or deployment configuration changes.

- Keep codex/elemental-v02 separate. DO NOT DEPLOY AUTOMATICALLY.

## Review focus

- Corrupt, future-version, blocked or prototype-bearing storage must not erase old progress or create reagent stock.
- Repeated Run must recalculate the same trial, not accumulate free products or duplicate journal/discovery writes.
- Nonstoichiometric, very dilute and overconcentrated inputs must preserve atoms/charge and make model-domain limits explicit.
- Switching modes, viewing products, importing and returning must preserve both labs' active configurations.
- Mobile stacking, unavailable WebGL, reduced motion and interrupted animations must preserve all click/keyboard controls and actual results.
